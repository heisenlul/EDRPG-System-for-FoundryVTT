Elite: Dangerous Role Playing Game for FoundryVTT
=================================================
Version 0.1.3
[![License](https://img.shields.io/github/license/ElSaico/edrpg-fvtt)](https://github.com/ElSaico/edrpg-fvtt/blob/main/LICENSE)


Enjoy the ELITE DANGEROUS universe via the Roleplaying Game made by Spidergames

With this addon, all needed things to play are aviable for players and GM to enjoy the game.

This addon includes:
PLAYER, VEHICLE AND SHIP SHEETS
CATALOG WITH WEAPONS, AMMO, AND EQUIPMENT FROM CORE AND ALL DLC INCLUDING EVOLUTION V.3
REAL TIME UPDATED CHARACTER SHEET WITH BACKGROUNDS, EHANCEMENTS, KARMA, SPECIAL ABILITIES AND MORE


How to use it??
1.Download the code 
2.Use the Npm run build command on the folder
3.Create an addon folder on your FoundryVTT data/systems folder to copy there the build
4.When build is done, copy the content builded to the FoundryVTT addon folder
    (cp index.js style.css system.json /home/Your User/route to FoundryVTT Folder/Data/systems/addon folder you created/)
5.Enjoy the system using it on Foundry VTT addons, you can find it inside FoundryVTT
    --Foundry VTT--Game Systems-->Install System-->Manifest URL-->Paste there your folder route--Done
